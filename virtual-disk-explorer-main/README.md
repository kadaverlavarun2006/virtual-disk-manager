# VDiskManager

Interactive disk scheduling and file allocation simulator built with React and Vite.

## Run locally

```sh
npm install
npm run dev
```

## Simulation history

No account or backend credentials are needed. Saved disk scheduling runs are stored in this browser's local storage and are not synced to a server or other devices. Use the History page to review or clear them. Clearing browser site data also removes saved runs.

Run `npm run build`, `npm run lint`, and `npm test` to validate the project.
